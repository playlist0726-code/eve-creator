Input Idea
혼자 노는 노인의, 따뜻하고 익살스러운 픽사풍 단편
장르: 코믹 드라마무드: 따뜻 · 익살 3D · 미국 애니grounded in «Geri's Game» (Pixar)
Core Twist

약자(소심한 자아)가 힘이 아니라 속임수로 이긴다. 상대가 곧 자기 자신이라, 이겨도 진 것도 결국 자기 — 자기와의 게임에서 스스로를 이기는 아이러니. (셋업: beat 2의 "자기와 둔다" → 페이오프: beat 4의 속임수)

Mise-en-scène Motif

마주 놓인 두 의자 = 자아의 분열. 빈 가을 공원 = 고독·황혼. 로우앵글 말 인서트 = 내적 위협을 크기로. 따뜻한 앰버 = 노스탤지어, 소품(틀니)의 소소함 = 유머.

Pacing Curve — 긴장도 곡선
감독이 시간에 걸쳐 긴장을 어떻게 쌓고 푸는가. 점 클릭 시 해당 SHOT으로 이동. HOOK가 CLIMAX의 트위스트를 가능케 한다.
Storyboard Sheet — 컷별 콘티
프레임 = 그림 자리 (해당 프롬프트로 GPT/DALL·E 생성 → storyboard_frames/beatN.png 저장 시 자동 표시). 우측 = ACTION · CAMERA · 미장셴 · 트위스트.

Method: «Geri's Game» (Pixar)를 비트 단위로 분석 → 긴장도·트위스트 메커니즘·미장셴·비트별 샷 문법을 Layer 2 스키마(SCHEMA_L2.md)로 구조화. 프레임 그림은 각 SHOT의 T2I 프롬프트로 외부 생성(예: GPT/DALL·E)해 채운다 — "시스템은 설계, 생성은 툴/사람".
