Start small: the minimum viable stack

You do not need every model. For a first short, use one image model for approved anchor frames, one image-to-video model for motion, and any editor you already know. Upgrade only when a shot has a specific unmet need.

1 · Still: GPT Image or your preferred image model → 2 · Motion: one I2V model → 3 · Edit: assemble, trim, and add sound. Reuse the same character and scene anchors across every shot.
